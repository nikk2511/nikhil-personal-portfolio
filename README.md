# Nikhil Singh - Personal Portfolio Website

A highly responsive, visually premium, mobile-first portfolio website showcasing B.Tech Computer Science journey achievements (2021-2025) and specialized post-graduation expertise in advanced AI engineering.

## 🚀 Features

- **Mobile-First UX**: Sleek bottom navigation bar, floating glassmorphic structures, and touch-swipe projects gallery.
- **Interactive AI Stack Explorer**: Deep-dives into LangChain, LangGraph, Advanced RAG, Fine-tuning, and Prompt Engineering, including complete implementation code templates.
- **Interactive RAG & Multi-Agent Simulator**: A step-by-step visual pipeline illustrating query translation, retrieval from Chroma DB, Cohere Cross-Encoder reranking, context assembly, and LLM output.
- **Virtual Agent Chat Widget**: Local chat simulator allowing visitors to "chat" with Nikhil's virtual assistant and query B.Tech coursework, GPA, skills, or projects.
- **Academic Timeline**: Complete roadmap of academic achievements, coursework, and 24-hour hackathons at Lloyd Institute of Engineering and Technology (LIET).
- **Credentials & Certifications**: Displaying verification badges for IBM Full-Stack Software Developer, Postman API, freeCodeCamp, and DevOps.

## 🛠️ Technology Stack

- **Frontend Structure**: HTML5 (Semantic elements)
- **Styling & Theme**: Vanilla CSS3 (Custom properties, HSL dark theme, glassmorphic layout, fluid grid systems, responsive media queries)
- **Logics & Simulations**: Vanilla JavaScript (ES6+, DOM rendering, scroll events, dynamic SVG connector calculators, simulator state machine, assistant message replies)
- **Assets & Icons**: FontAwesome Icons (v6), Google Fonts (Outfit, Inter, Fira Code)

## 💻 Local Preview

1. Clone this repository:
   ```bash
   git clone https://github.com/nikk2511/nikhil-personal-portfolio.git
   ```
2. Navigate to the project directory and spin up a local server:
   - **Using Python**:
     ```bash
     python -m http.server 8000
     ```
   - **Using Node.js**:
     ```bash
     npx http-server -p 8000
     ```
3. Open `http://localhost:8000` in your web browser.
